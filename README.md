# KnightBite Website (Recreation)

A front-end recreation of the KnightBite website, built with HTML and CSS to practise multi-page layout, navigation and consistent styling.

> Recreation built for learning and practice. Not affiliated with KnightBite.

## Screenshot

![KnightBite home page](screenshots/home.png)

## About

This project recreates the look and structure of the KnightBite website as a static front-end. It focuses on layout, typography, colour and component styling. There is no backend and no database.

## Tech Stack

- HTML5
- CSS3

## What I Practised

- Structuring a multi-page website with semantic HTML
- Building page layouts with Flexbox and CSS Grid
- Reusing consistent navigation, header and footer styles across pages
- Styling typography, buttons, cards and image sections

## How to Run

1. Clone the repository
   ```bash
   git clone https://github.com/Shamitha-2330/knightbite-website.git
   ```
2. Open `index.html` in any browser, or use the Live Server extension in VS Code.

## Known Limitations

- Desktop layout only; not yet responsive for tablet and mobile
- Static pages with no interactivity

## Planned Improvements
